LFH (standing for "Liam's Font Header") is a 3 part file Header, the first part consists of the following data types and values:

(Version 1 is the old System so just one Header, Version 2 is the new 3 Header system)

uint8_t headerStart     = 0xFF
uint8_t Version		= 0x02
uint32_t signature      = "LFH" + 0x01
uint8_t fontWidth       = 0x05
uint8_t fontHeight      = 0x07
uint8_t fontChars       = 0xD9
uint8_t isExtendedAscii = 0x01
uint8_t headerEnd       = 0xFF

[PART 2]

uint8_t headerStart	= 0xEE
uint32_t signature 	= "LFH" + 0x02
uint32_t length		= CHARACTER_COUNT * (sizeof(uint8_t) + sizeof(uint32_t))
uint32_t offsetList	= OFFSET_TO_LIST
uint8_t headerEnd	= 0xEE

the 3rd part is the actual list built up like this:
CHARACTER_COUNT ammount of:
uint8_t letter
uint32_t offset
.
.
