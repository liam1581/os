version 1 of the LFH (Liam's Font Header) is a 10 byte long file header consisting of the following data types and default and/or hardcoded values:
everything with a "!" in the spacing is a hard coded value that cant be changed because elsewise the header would be invalid!

uint8_t header_start !  = 0xFF
uint32_t signature   !  = "LFH" + 0x00
uint8_t font_width   !  = 0x05
uint8_t font_height  !  = 0x07
uint8_t font_chars      = 0xD9
uint8_t extended_ascii  = 0x01
uint8_t header_end   !  = 0xFF

this describes a font with 0xD9 (217) characters which supports extended ascii and is (hard coded to be) a 5x7 pixel font

------------------------------

version 2 of the LFH header is 25 + X byte long header structure consisting of the following 3 parts
same as version 1: everything with a "!" in the spacing is a hard coded value that cant be changed because elsewise the header would be invalid!

[PART 1 (similar to version 1)]
uint8_t header_start !  = 0xFF
uint8_t version         = 0x02
uint32_t signature   !  = "LFH" + 0x01      [0x01 because it is the first part of the header]
uint8_t font_width      = 0x05
uint8_t font_height     = 0x07
uint8_t font_chars      = 0xD9
uint8_t extended_ascii  = 0x01
uint8_t header_end   !  = 0xFF

[PART 2 (the character list)]
uint8_t header_start !  = 0xEE
uint32_t signature   !  = "LFH" + 0x02      [0x02 because it is the second part of the header]
uint32_t length         = XXXX              [Calculated by the following formula: font_chars * (sizeof(uint8_t) + sizeof(uint32_t)) // font_chars * 5
uint32_t list           = XXXX              [The byte offset from the start of the file to the list of characters, should be 25 but can be variable for some funny message in the header file i guess)]
uint8_t header_end   !  = 0xEE

------------------------------

[PART 3 (the list of characters)]
font_chars ammount of:
uint8_t letter                              [In extended ascii -- Windows-1252]
uint32_t offset                             [The byte offset from the start of the file to the specified character]
