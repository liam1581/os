LFH (standing for "Liam's Font Header") is 10 bytes long and consists of the following data types and values:

uint8_t headerStart     = 0xFF
uint32_t signature      = "LFH" + 0x00
uint8_t fontWidth       = 0x05
uint8_t fontHeight      = 0x07
uint8_t fontChars       = 0xD9
uint8_t isExtendedAscii = 0x01
uint8_t headerEnd       = 0xFF

the width and height are currently hard coded to be 5x7 aswell as the the fact if it is extendedAscii or not (has to be) and the character count is also hardcoded to 217/D9
